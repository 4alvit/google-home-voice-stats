# OpenSSF evidence index

The official badge service determines awarded status. This index records source evidence and remaining limitations.

- README.md and architecture.md describe purpose, configuration and boundaries.
- CONTRIBUTING.md and SECURITY.md define public contribution/review and confidential vulnerability reporting.
- docs/tls-policy.md defines the complete direct speech workflow, real client/server key tests and optional-integration limits.
- docs/quality.md records test, scan, dependency and maintainer evidence without transferring old results to new source.
- RELEASING.md, CHANGELOG.md and the release workflows describe source-bound RC/stable handling; current stable v0.3.2 is a published release.
- GOVERNANCE.md, CODE_OF_CONDUCT.md and ROADMAP.md describe roles, confidential conduct contact and the next year's maintenance priorities.

Silver continuity requirements are unmet: there is no backup person or tested one-week recovery. New TLS tests are not a claim of universal Cast/HA deployment security, new fuzzing, a physical-device test or independent certification.
